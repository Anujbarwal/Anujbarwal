THE APPROACH

Less tutorial-hopping.
More making things work.

This plan assumes no coding or computer-science background. It starts with the structure of a web page, moves carefully through JavaScript, then connects the front end, server, database, tests, and deployment into complete applications.

One layer at a time.

Core languageDOM & eventsAsync JavaScript

Git, GitHub & going live

Track changes with Git, write useful commits, work with a remote repository, and put projects online. Deploy early, then deploy every new project.

THE REPEATABLE LOOP

Do this every session.

Small lessons. Lots of deliberate practice. A finished thing to show for it.

01

Learn one thing

Read or watch for 20–30 minutes. Focus on one small idea.

02

Type it yourself

Run the example, make a deliberate change, and predict what happens.

03

Build something new

Use the idea in a tiny project that wasn't in the lesson.

04

Write & revisit

Explain it in your own words, then try to rebuild it from memory next week.

CHECK YOUR UNDERSTANDING

Milestones are self-tests.

If a test is hard, revisit the specific skill and try again. No need to start over or rush ahead.

AFTER MONTH 2

Build a page from a screenshot

Make a responsive landing page without a tutorial open. Explain the box model and specificity.

AFTER MONTH 5

Build a small API-powered app

Fetch, display, and filter data with a loading state. Explain async/await and debug a broken function.

AFTER MONTH 8

Build a three-route React app

Fetch a list, build a detail page, add a filter, and explain props versus state.

AFTER MONTH 11

Design data and an API

Model related tables, write a join, and build a validated CRUD API from an empty folder.

AFTER MONTH 14

Deploy from a clean start

Put a project online with HTTPS and a database. Explain how its login works end to end.

AROUND MONTH 17

Show work you can explain

Three live flagship projects, tests, a clear resume, and mock interviews you have reviewed.
