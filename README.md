## Learning roadmap

This is a learning plan, not a claim that every milestone is complete. I update it as I build and learn.

| Phase | Focus | Project milestone |
| :--- | :--- | :--- |
| 01 | HTML and semantic structure | Build static pages from scratch |
| 02 | CSS, responsive layouts, and Tailwind | Create a responsive multi-page site |
| 03 | JavaScript, DOM, and async programming | Build interactive apps using public APIs |
| 04 | Git, GitHub, and deployment | Deploy projects with version control |
| 05 | React, TypeScript, and routing | Build a multi-page frontend application |
| 06 | Node.js, Express, and REST APIs | Connect a frontend to a custom API |
| 07 | PostgreSQL, SQL, and an ORM | Design and query a relational database |
| 08 | Authentication and testing | Add sessions or tokens, authorization, and automated tests |
| 09 | Docker and CI/CD | Containerize and deploy an application |
| 10 | Portfolio projects | Ship projects that solve real problems |
